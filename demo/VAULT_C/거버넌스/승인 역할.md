# 승인 역할

source owner는 입력 사용 권한과 데이터 등급을 확인한다. operator는 tool 실행과
상태 확인을 맡는다. curator는 taxonomy 전체와 각 cluster revision을 source와
대조해 승인한다. release owner는 verify된 output의 배포 여부를 결정한다.

provider는 어느 단계에서도 승인 주체가 아니다. critic 결과가 major 또는
critical이면 curator가 waiver로 우회할 수 없다. minor finding과 omission에는
각 항목에 결합된 rationale이 필요하다.

변경 흐름은 [[운영/변경 관리]], 감사 자료는 [[거버넌스/감사 응답 절차]]에 있다.
