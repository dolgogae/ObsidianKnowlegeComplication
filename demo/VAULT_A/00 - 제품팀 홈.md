# Atlas 제품팀 홈

Atlas는 여러 팀의 흩어진 Markdown 지식을 검색하고, 근거가 남는 하나의
업무 지식 공간으로 정리하는 프로젝트다. 제품팀은 사용자가 결과를 신뢰할 수
있는지, 검토 부담이 감당 가능한지, 원본으로 돌아갈 수 있는지를 우선한다.

## 이번 주 초점

파일럿 팀이 서로 다른 표현을 쓰는 동일 개념을 얼마나 잘 묶는지 확인한다.
합성 결과가 단정적으로 보이지 않도록 출처와 충돌 문맥을 함께 보여준다.
