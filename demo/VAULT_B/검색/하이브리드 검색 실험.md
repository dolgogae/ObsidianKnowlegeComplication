# 하이브리드 검색 실험

장애명, component 이름, error code가 들어간 질의에서는 lexical match와 link
neighbor가 semantic vector보다 정확했다. 문제 상황을 자연어로 설명한 질의는
semantic 후보가 더 많은 관련 문서를 찾았다.

현재 엔지니어링 샘플에서는 keyword와 link 신호를 오십오 퍼센트 반영한 조합이
안정적이었다. 제품팀은 의미 신호 육십 퍼센트를 제안한다. 두 실험은 query
cohort가 다르므로 숫자만 비교해 하나를 승자로 정하지 않는다.

최종 taxonomy 후보에는 exact, title, alias, link, semantic 이유를 모두 기록해
organizer가 한 신호에 의존하지 않게 한다.
