# 권한 모델

파일럿의 역할은 operator, curator, provider로 구분한다. operator는 실행과
source 선택을 담당하고, curator는 taxonomy와 cluster revision을 명시적으로
승인한다. provider는 구조화된 제안을 반환할 뿐 승인 권한이 없다.

로컬 파일 권한은 협업 권한 시스템을 대체하지 않는다. project directory가
평문 상태를 포함하므로 접근 가능한 사용자 범위를 운영 절차에서 제한한다.

향후 조직 계정 연동이 추가되기 전까지 approval의 curator ID는 감사 표식이지
강한 외부 신원 증명으로 해석하지 않는다.
