# 기술 용어집

## corpus

snapshot에서 파싱해 hash로 봉인한 document, block, metadata의 전체 집합.

## task key

stage, prompt, schema, source, provider identity와 options에 결합된 재개 단위.

## revision

taxonomy, proposal, critic 결과가 바뀔 때 append되는 불변 상태. 이전 revision을
덮어쓰지 않는다.

## cluster

하나의 synthesis proposal과 canonical note를 만드는 document 집합.
[[프로젝트/Atlas 기술 범위]]와 [[아키텍처/데이터 모델]]에서 실제 쓰임을 볼 수 있다.
