# 서비스 수준 목표

파일럿에서는 상시 서비스 가용성보다 실행의 안전한 완료와 복구 가능성을
측정한다. terminal이 진행 중 상태를 표시하고, 실패한 단계와 재개 지점이 명확해야
한다.

## 측정 항목

- source snapshot 후 원본 hash가 변하지 않음
- 실패 시 요청 output 경로에 partial artifact가 없음
- completed provider task가 동일 identity에서 재사용됨
- compile 후 independent verify가 통과함
- 검토되지 않은 revision이 materialize되지 않음

수치는 [[리서치/평가 데이터셋]]의 실행 기록으로 계산한다. 장애 대응 시간은
[[운영/장애 대응 절차]]에서 별도로 다룬다.
