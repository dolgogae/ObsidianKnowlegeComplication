# 보존 정책

고객 운영팀은 감사와 재현을 위해 project journal, provider recording, approval,
verified output을 구십 일 동안 보존하는 안을 제안한다. active output의 근거가
되는 plan과 recording은 그보다 먼저 지우지 않는다.

제품팀 문서에는 기본 삼십 일 보존 제안이 있다고 전달받았다. 두 기간은 대상과
법적 요구가 다를 수 있으므로 다수결로 하나를 선택하지 않는다. [[회의/고객 자문 회의]]에서
내부 파일럿과 고객 감사 자료를 구분해 합의해야 한다.

삭제 전 검증은 [[운영/백업 검증]], 책임자는 [[거버넌스/승인 역할]]을 참고한다.
