# 비기능 요구사항

파일럿 데이터 규모에서는 사용자가 진행 상황을 계속 볼 수 있어야 한다. 긴
작업 중에도 화면이 멈춘 것처럼 보여서는 안 되며, 결과를 게시하기 전까지는
취소가 가능해야 한다.

동일한 source, 승인, provider recording으로 다시 빌드하면 같은 결과가 나와야
한다. 절대 경로, 실행 시각, 호스트 이름은 지식 결과의 정체성에 포함하지
않는다. 오류 메시지에는 원문 전체나 인증 정보가 노출되지 않아야 한다.

초기 파일럿 목표는 문서 수백 개 이하의 팀 Vault다. 대규모 성능 목표는 별도
검증 후 약속하며, 파일럿 결과를 유일한 백업으로 사용하지 않는다.
