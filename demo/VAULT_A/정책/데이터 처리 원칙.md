# 데이터 처리 원칙

source에는 공개 범위가 다른 문서가 섞일 수 있다. provider 호출 전에 어떤
역할이 어떤 데이터를 처리하는지 보여주고, 원격 전송은 실행별 동의를 받는다.

민감한 내용이 탐지되면 의미 분류와 해당 cluster 합성은 로컬 처리 경로를
사용한다. 탐지 결과에는 원문 값이 아니라 범주와 위치, 검증용 해시만 남긴다.

프로젝트 상태에는 source 경로와 AI 기록이 평문으로 남을 수 있으므로 공유
폴더에 만들지 않는다. 인증 정보의 실제 값은 프로젝트 파일에 저장하지 않는다.
