# 검색 용어집

## canonical 문서

여러 source의 근거를 바탕으로 승인된 주제별 대표 문서. 원본을 지우는 문서가
아니라 탐색 시작점을 제공한다.

## source 문서

입력 Vault에 있던 원본 문서. compile 동안 수정되지 않으며 provenance의 기준이
된다.

## taxonomy

모든 문서를 정확히 한 주제에 배정하는 전체 분류 체계.

## cluster

하나의 canonical 문서로 합성할 관련 source 문서 묶음.

엔지니어링 팀은 cluster를 작업 단위라고 부르기도 한다. 이 Vault에서는
[[제품/Atlas 개요]]와 [[제품/핵심 시나리오]]가 용어의 실제 사용 맥락을 보여준다.
