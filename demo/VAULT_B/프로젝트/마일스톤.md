# 엔지니어링 마일스톤

## M1: 로컬 경로 완성

프로젝트 생성, source 등록, provider 설정, taxonomy 승인, cluster 승인,
directory compile과 verify를 한 흐름으로 연결한다.

## M2: 실패 복구

provider timeout, 잘못된 schema, 작업 취소, 프로세스 재시작 뒤 completed task를
재사용하는지 검증한다.

## M3: 파일럿 준비

hostile path, 기존 출력, source 변경, stale approval을 거부하는 회귀 테스트와
운영 runbook을 마친다. 엔지니어링 기준 파일럿 시작 후보는 2026-11-05다.
