# 고객 자문 회의

참여자는 통합된 답 하나보다 답이 달라지는 조건을 빨리 찾는 것을 중요하게
보았다. 파일럿 날짜, 보존 기간, 검색 방식처럼 팀별 가정이 다른 주제는 한쪽을
삭제하지 말고 비교 표로 보여달라고 요청했다.

또한 output의 링크가 원본 source로 직접 열리는지, 원본이 없는 환경에서는 어떤
provenance 정보가 남는지 질문했다. 이에 따라 [[거버넌스/감사 응답 절차]]와
[[고객/지원 문의 패턴]]을 교육 자료에 포함한다.

다음 회의에서는 [[거버넌스/보존 정책]]의 내부 파일럿과 고객 감사 범위를 분리해
검토한다.
