# 정책 MOC

[[정책/데이터 처리 원칙]]은 provider 공개와 credential 경계를 설명한다.
[[정책/콘텐츠 수명주기]]는 project 기록과 output을 얼마나 보존할지 다룬다.

두 문서는 [[제품/비기능 요구사항]]의 privacy와 reproducibility 조건을 구체화한다.
보존 기간은 아직 운영팀 관점과 합의되지 않았으므로 proposed 상태를 유지한다.
