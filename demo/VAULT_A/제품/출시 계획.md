# 출시 계획

제품팀은 내부 파일럿 시작일을 2026-10-15로 제안한다. 이 날짜에는 Markdown
통합, taxonomy 검토, cluster 승인, directory 출력 검증만 포함한다.

## 단계

- 준비: 파일럿 source 선정과 민감정보 사전 점검
- 내부 사용: 제품팀과 지원팀이 한 주 동안 결과를 비교
- 확대 판단: 누락과 잘못된 합성 사례를 검토하고 다음 범위 결정

첨부 파일, Canvas, 모바일 설치는 출시 범위가 아니다. 엔지니어링 팀은 안정화
기간 때문에 더 늦은 날짜를 제시했으므로 [[회의/출시일 논의]]에서 최종 합의가
필요하다.
