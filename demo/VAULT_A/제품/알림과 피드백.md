# 알림과 피드백

사용자에게 필요한 알림은 작업 시작, 원격 전송 동의, 검토 필요, 취소 가능
여부 변경, 검증 성공 또는 실패다. 단순 진행률보다 현재 단계와 다음 사용자의
행동을 알려주는 것이 중요하다.

AI 제안이 마음에 들지 않을 때 사용자는 자유 형식 피드백으로 새 revision을
요청할 수 있어야 한다. 이전 제안과 승인은 기록으로 남고, 새 제안이 기존
승인을 몰래 이어받으면 안 된다.

향후에는 문서별 댓글보다 cluster 단위 검토가 먼저다. 지나치게 세분화된 알림은
검토 피로를 높이므로 파일럿 관찰 후 조정한다.
