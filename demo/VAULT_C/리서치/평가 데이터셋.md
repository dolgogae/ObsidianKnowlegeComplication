# 평가 데이터셋

평가 corpus는 제품, 엔지니어링, 고객 운영 Vault의 Markdown을 사용한다. exact
duplicate, near duplicate, 서로 보완하는 기록, 날짜와 적용 범위가 충돌하는
기록을 모두 포함한다.

## cohort

| cohort | 예시 | 기대 관찰 |
|---|---|---|
| exact | 공통 운영 원칙 | 중복 provenance 유지 |
| terminology | cluster와 주제 묶음 | alias와 문맥 연결 |
| temporal | 서로 다른 파일럿 날짜 | 조건별 주장 보존 |
| policy | 보존 기간 제안 | 주체와 범위 유지 |
| operational | provider 장애 | 실행 가능한 runbook 연결 |

질문 목록은 [[리서치/파일럿 질의 세트]], 채점 기준은 [[리서치/합성 품질 기준]]에
분리한다.
