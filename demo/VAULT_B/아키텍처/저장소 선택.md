# 저장소 선택

작은 설정은 canonical TOML 또는 JSON으로, 실행 이력과 현재 pointer는 SQLite로,
큰 immutable payload는 content-addressed object로 저장한다. SQLite는 foreign
key와 WAL을 사용하고 중요한 경계에서 동기화한다.

project 데이터는 암호화 저장소가 아니다. source 경로, taxonomy, proposal,
approval, provider recording이 평문일 수 있다. 따라서 공유 폴더에 두지 않고
가능한 플랫폼에서는 private permission을 적용한다.

실제 credential 값은 object나 SQLite에 저장하지 않는다. 환경변수 이름 또는
OS keychain account reference만 보존한다.
