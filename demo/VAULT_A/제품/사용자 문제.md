# 사용자 문제

팀이 성장하면서 같은 결정이 제품 문서, 기술 문서, 지원 메모에 각각 기록된다.
검색 결과는 많지만 어느 문서가 최신인지, 표현만 다른 것인지, 실제로 충돌하는
것인지 판단하는 데 시간이 든다.

## 관찰된 불편

- 새 구성원은 같은 용어의 정의가 팀별로 달라 온보딩에 어려움을 겪는다.
- 회의에서 결정된 변경이 오래된 개요 문서에 반영되지 않는다.
- 검색 상위 결과가 오래된 복사본이면 사용자는 잘못된 결론을 얻는다.
- 문서를 합친 뒤 원래 표현과 작성 맥락을 찾기 어렵다.
- 자동 요약이 누락을 만들더라도 검토자는 무엇이 빠졌는지 알기 어렵다.

사용자는 더 많은 문서보다 검토 가능한 하나의 관점을 원한다. 다만 원본의
차이를 숨기는 통합은 신뢰를 오히려 낮춘다. 관련 근거는 [[리서치/인터뷰 요약 - 연구원]]과
[[리서치/인터뷰 요약 - 지원팀]]에 있다.
