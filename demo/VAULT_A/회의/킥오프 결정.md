# 킥오프 결정

## 결정

- 프로젝트 이름은 Atlas를 사용한다.
- source Vault는 읽기 전용으로 취급한다.
- 첫 결과물은 새로운 directory이며 기존 Vault 위에 덮어쓰지 않는다.
- AI는 taxonomy와 합성을 제안하지만 승인 권한은 갖지 않는다.
- 파일럿은 제품, 엔지니어링, 고객 운영의 세 Vault로 진행한다.
