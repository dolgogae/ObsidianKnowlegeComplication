# 운영 MOC

## 정상 경로

[[운영/배포 전략]]과 [[운영/관측성]]은 파일럿 build와 실행 상태를 다룬다.

[[운영/백업과 복구]]를 따른다. 실행 가능 여부는 [[품질/릴리스 체크리스트]]와
대조한다.
