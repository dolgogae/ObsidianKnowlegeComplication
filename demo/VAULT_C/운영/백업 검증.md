# 백업 검증

source Vault, Atlas project, verified output은 서로 다른 복구 자산이다. output은
원본의 완전한 백업이 아니고 project만으로 source bytes를 복원할 수도 없다.

## 분기별 훈련

- source 사본에서 file hash와 link graph를 확인한다.
- project journal과 object reference가 열리는지 확인한다.
- provider 없이 approved integration plan을 compile한다.
- 생성한 directory를 별도 verify한다.
- 기존 output 경로가 보존되는지 확인한다.

보존 기간은 [[거버넌스/보존 정책]], 실패 대응은 [[운영/장애 대응 절차]]를 따른다.
