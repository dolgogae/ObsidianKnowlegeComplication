# 감사 응답 절차

특정 output 문장의 근거를 요청받으면 먼저 artifact 전체 verify를 실행한다. 이후
해당 path의 explanation에서 integration plan, cluster, proposal, critic, approval,
source document와 block까지 연결된 record를 제공한다.

내부 일관성 검증을 외부 작성자 신원이나 법적 진실성 보증으로 표현하지 않는다.
source locator가 redacted되어도 stable source ID와 logical path, content identity로
근거를 설명할 수 있어야 한다.

데이터 공개 수준은 [[거버넌스/데이터 분류]], 보존 여부는 [[거버넌스/보존 정책]]과
함께 판단한다.
