# 회의 MOC

[[회의/파일럿 검토]]는 안전한 내부 사용 조건을, [[회의/고객 자문 회의]]는
고객이 실제로 원하는 검토 경험을 기록한다.

[[회의/출시일 조정]]에는 고객 운영의 2026-10-29 제안과 엔지니어링의 더 늦은
준비 조건이 함께 남아 있다. 날짜 하나만 떼어 최종 약속으로 해석하지 않는다.

후속 작업은 [[운영/출시 준비도]]와 [[로드맵/고객 운영 로드맵]]으로 연결한다.
