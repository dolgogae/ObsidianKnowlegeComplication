# 백업과 복구

source Vault는 기존 백업 정책을 그대로 유지한다. Atlas output은 source를
대체하는 백업이 아니다. project directory와 검증된 output을 함께 보존해야
승인과 provenance를 감사할 수 있다.

중단 복구 순서는 project lock 상태 확인, journal integrity 확인, 마지막 complete
task 확인, 같은 입력 identity로 재개다. 손상된 DB를 수동으로 편집해 완료로
표시하지 않는다.

복구 훈련에서는 provider가 없는 상태에서도 이미 승인된 plan으로 compile과
verify가 가능한지 확인한다.
