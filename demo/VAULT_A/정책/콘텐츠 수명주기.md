# 콘텐츠 수명주기

제품팀은 통합 결과를 매주 다시 만들고 최근 삼십 일의 작업 기록을 기본 보존
기간으로 제안한다. 승인의 근거가 되는 recording과 plan은 결과를 사용하는 동안
함께 유지해야 한다.

source에서 문서가 삭제되어도 과거 통합 결과의 provenance를 임의로 다시 쓰지
않는다. 새 실행은 새 source snapshot으로 만들고 이전 결과는 별도 정책에 따라
보관하거나 폐기한다.

고객 운영팀은 감사 요구 때문에 더 긴 기간을 제안하고 있으므로 하나의 전사
정책으로 확정되지 않았다.
