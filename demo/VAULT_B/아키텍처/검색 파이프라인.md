# 검색 파이프라인

문서를 안정된 순서로 chunk한 뒤 하나의 embedding model 공간에서 vector를
만든다. semantic neighbor만으로 taxonomy를 결정하지 않고 exact duplicate,
title, alias, wikilink, lexical similarity 후보를 합친다.

현재 작은 파일럿은 exact cosine 비교를 사용한다. 대규모 경로에서는 고정 seed와
삽입 순서를 가진 approximate index가 필요하지만 아직 기본 경로로 승격하지
않았다.

엔지니어링 실험에서는 keyword와 link 신호를 오십오 퍼센트, semantic 신호를
사십오 퍼센트로 둔 조합이 장애 문서 검색에 더 안정적이었다. 제품팀의 육십 대
사십 가설과 다르므로 [[검색/하이브리드 검색 실험]]에서 조건을 비교한다.
