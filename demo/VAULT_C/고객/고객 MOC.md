# 고객 MOC

## 시작

[[고객/파일럿 개요]]에서 대상과 성공 조건을 확인하고,
[[고객/도입 플레이북]]과 [[고객/온보딩 체크리스트]]로 실행한다.

## 사용 중

[[고객/지원 문의 패턴]]은 실제 질문을 분류하고, [[고객/교육 계획]]은 반복되는
혼란을 교육 과정으로 바꾼다. 계약 전 확인 사항은 [[고객/엔터프라이즈 요구사항]]에
분리한다.
