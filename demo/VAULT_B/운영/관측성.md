# 관측성

상태 줄에는 현재 stage, 처리 중 cluster, 완료 수와 전체 수, 취소 가능 여부를
표시한다. journal에는 task 시작, 성공, 실패, recording hash를 append한다.

로그는 diagnostic code와 object identity 중심으로 남긴다. source 원문, provider
credential, authorization header, key 길이는 기록하지 않는다. 오류 메시지에
provider가 반환한 민감한 body 전체를 그대로 붙이지 않는다.

파일럿 동안 측정할 운영 항목은 stage별 시간, 재시도 횟수, cache 재사용 수,
검토 revision 수다. 단순 성공률만으로 합성 품질을 평가하지 않는다.
