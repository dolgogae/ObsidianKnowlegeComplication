# 검색 평가

지원 담당자의 질의는 정확한 component 명칭과 일반적인 문제 설명이 섞여 있다.
키워드만 사용하면 표현이 다른 정책 문서를 놓치고, semantic 후보만 사용하면
정확한 runbook 제목과 날짜 기록의 순위가 흔들렸다.

> [!example] 평가에 사용한 질문
> ![[리서치/파일럿 질의 세트#^pilot-queries]]

현재 관찰은 lexical, link, title, alias, semantic 후보를 union한 뒤 사람이
taxonomy를 검토하는 방식이 안정적이라는 것이다. 단일 점수를 merge authority로
사용하지 않는다.

사용자 체감은 [[고객/지원 문의 패턴]], 데이터 범위는 [[리서치/평가 데이터셋]]과
함께 해석한다.
