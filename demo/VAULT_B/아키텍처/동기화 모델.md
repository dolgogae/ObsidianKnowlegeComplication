# 동기화 모델

Atlas는 양방향 동기화 도구가 아니다. 각 실행은 source의 immutable snapshot을
만들고 새로운 output을 게시한다. 이전 output이나 source에 결과를 merge하지
않는다.

source set이 바뀌면 새 run identity가 생기고 이전 taxonomy와 cluster 승인은
stale이 된다. 완료된 task는 입력 hash와 provider identity가 정확히 같은 경우에만
재사용한다.

향후 증분 계산이 들어가더라도 최종 integration plan과 output은 전체 closure를
검증해야 한다. cache hit는 승인이나 provenance 검증을 건너뛰는 권한이 아니다.
