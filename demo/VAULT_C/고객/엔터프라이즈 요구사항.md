# 엔터프라이즈 요구사항

기업 파일럿에서는 source가 외부 provider로 나가는 조건, credential 저장 위치,
approval 주체, output 보존 기간을 사전에 설명해야 한다.

## 필수 질문

- 민감 finding이 있을 때 어떤 role이 local로 강제되는가
- project와 recording에 어떤 평문 metadata가 남는가
- output이 source를 덮어쓰지 않는다는 것을 어떻게 검증하는가
- 특정 canonical 문장의 source와 approval을 어떻게 설명하는가
- 오류와 취소 시 partial output이 보이는가

답변 근거는 [[거버넌스/데이터 분류]], [[거버넌스/승인 역할]],
[[거버넌스/보존 정책]], [[운영/백업 검증]]에 분산되어 있다.
