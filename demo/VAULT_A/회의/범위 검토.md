# 범위 검토

파일럿의 목적은 완전한 문서 플랫폼을 출시하는 것이 아니라 통합 검토 흐름이
실제 업무에서 유용한지 확인하는 것이다.

## 포함

Markdown parsing, source별 provenance, taxonomy 수정, cluster 합성 검토,
provider-free compile, 독립 verify를 포함한다.

## 제외

첨부 파일 복사, Canvas 재작성, 모바일 설치, 자동 승인, 조직 전체 권한 연동은
이번 범위에 포함하지 않는다. 제외 기능을 지원한다고 문서에 표현하지 않는다.

운영팀은 고객 파일럿에 첨부가 필요하다고 보았지만, 제품팀은 검증 가능한 작은
범위로 시작하기로 했다.
