# 데이터 모델

핵심 객체는 source snapshot, document, block, taxonomy cluster, synthesis
proposal, critic report, approval, integration plan, output record다.

Document는 source ID와 normalized logical path를 가지며, Block은 원문 위치와
content hash를 가진다. taxonomy는 모든 Document를 정확히 한 cluster에 배정한다.
proposal은 모든 Block과 frontmatter value에 disposition을 제공해야 한다.

Approval은 사람이 읽은 화면이 아니라 정확한 revision hash에 결합된다. output
provenance는 canonical note에서 proposal, critic, approval, evidence까지 닫힌
경로를 제공한다.
