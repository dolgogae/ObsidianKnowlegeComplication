# 도입 플레이북

## 준비

목적과 범위를 [[고객/파일럿 개요]]에서 합의한다. source owner가 각 Vault의
사용 권한과 데이터 분류를 확인하고 [[거버넌스/데이터 분류]]에 따라 provider
route를 정한다.

## 첫 실행

[[고객/온보딩 체크리스트]]를 따라 provider 연결, Vault 선택, preflight를
완료한다. taxonomy 이름은 조직 용어와 맞는지 검토하고, cluster별 누락과 충돌을
확인한 뒤 승인한다.

## 운영 전환

verify된 output만 공유한다. 문의 창구와 장애 역할은 [[운영/장애 대응 절차]],
변경 주기는 [[운영/변경 관리]]에서 확인한다.
