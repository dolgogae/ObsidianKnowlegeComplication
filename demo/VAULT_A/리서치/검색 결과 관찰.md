# 검색 결과 관찰

파일럿 질의에서는 제품명이 정확히 들어간 질문은 키워드 검색이 안정적이었다.
반면 사용자가 문제 상황만 설명한 질문은 의미 기반 후보가 더 관련 있는 문서를
찾았다. 둘 중 하나만 사용하면 긴 꼬리 질의에서 누락이 발생했다.

제품팀은 초기 화면에서 의미 후보를 더 강하게 보여주는 방안을 선호한다. 임시
가설은 의미 신호를 육십 퍼센트, 단어와 링크 신호를 사십 퍼센트 반영하는 것이다.
이 비율은 [[제품/성공 지표]]의 검토 결과 없이 확정하지 않는다.

복사된 문서가 여러 Vault에 있다고 해서 독립적인 근거가 늘어난 것으로 계산하면
안 된다.
