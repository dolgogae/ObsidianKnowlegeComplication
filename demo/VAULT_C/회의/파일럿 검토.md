# 파일럿 검토

## 합의

- source Vault를 유일한 원본으로 유지한다.
- 첫 파일럿은 Markdown 결과만 검토한다.
- taxonomy와 모든 cluster를 사람이 승인한다.
- 검증된 output도 유일한 백업으로 사용하지 않는다.
- 고객 식별 정보가 있는 실제 문서는 demo에 넣지 않는다.

^pilot-guardrail
