# 결정 MOC

[[결정/ADR - Rust 코어]]는 compilation policy를 하나의 library에 두는 결정을,
[[결정/ADR - SQLite 채택]]은 resumable journal을 transaction으로 관리하는 결정을
기록한다.

두 결정은 [[아키텍처/시스템 개요]]와 [[아키텍처/저장소 선택]]에서 실제 설계로
이어진다. 변경하려면 기존 문서를 덮어쓰지 않고 새 decision note를 만든다.
