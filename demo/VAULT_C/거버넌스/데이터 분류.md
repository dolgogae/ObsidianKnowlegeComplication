# 데이터 분류

## 공개

외부 공개가 승인된 일반 제품 설명. 승인된 remote provider route에서 처리할 수
있지만 실행별 disclosure 동의는 별도로 필요하다.

## 내부

조직 내부 업무 문서. provider 계약과 route를 확인한 경우에만 제한적으로
처리한다.

## 제한

개인 식별 정보, credential, 비공개 고객 자료가 포함될 가능성이 있는 문서.
민감 finding이 있으면 semantic role과 해당 cluster role을 local로 제한한다.
