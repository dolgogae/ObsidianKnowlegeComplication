# 시스템 개요

Atlas는 core compiler, application service, provider adapter, CLI와 TUI로
구성된다. canonical state와 compilation policy는 core와 application에 있고,
화면이나 provider가 이를 소유하지 않는다.

입력은 신뢰하지 않는 immutable snapshot이다. provider 출력은 proposal이며
schema, source evidence, current hash를 검증한다. 승인된 integration plan만
offline compiler에 전달한다.

project directory는 manifest, SQLite journal, immutable object store, build
workspace를 가진다. 단일 writer가 상태를 변경하고 긴 작업은 bounded worker에서
실행한다. 관련 결정은 [[결정/ADR - Rust 코어]]와 [[결정/ADR - SQLite 채택]]에
기록했다.
