# 검색 MOC

[[아키텍처/검색 파이프라인]]은 candidate 생성의 계약을 설명하고,
[[검색/하이브리드 검색 실험]]은 서로 다른 query cohort의 관찰을 기록한다.

semantic score는 merge 권한이 아니며 taxonomy는 전체 document coverage 검증과
curator 승인을 거친다. 데이터 객체는 [[아키텍처/데이터 모델]]을 참고한다.
