# 보안 점검

- source symlink와 managed output을 입력으로 선택할 수 없는지 확인
- archive path traversal과 과도한 압축 해제를 거부하는지 확인
- Markdown의 도구 실행 지시를 data로만 취급하는지 확인
- 원격 provider 호출 전에 disclosure 범위와 동의를 보여주는지 확인
- project와 로그에 credential 실제 값이 없는지 확인
- terminal control 문자를 escape하는지 확인
- 기존 file, directory, link를 output으로 덮어쓰지 않는지 확인

이 demo는 정상 기능용이며 hostile payload를 포함하지 않는다. 공격 입력 검증은
격리된 test corpus에서 별도로 수행한다.
