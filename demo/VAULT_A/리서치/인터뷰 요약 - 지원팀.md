# 인터뷰 요약: 지원 역할

지원팀은 장애 대응 중에 오래된 문서를 열 가능성이 가장 큰 문제라고 말했다.
문서 제목은 같지만 대상 버전이나 배포 환경이 다른 경우가 많다. 검색 결과에서
최신 문서만 강제로 남기면 과거 고객 환경을 설명할 근거가 사라질 수 있다.

지원 담당자는 canonical 문서에서 적용 범위를 먼저 보고, 필요할 때 원본으로
이동하기를 원한다. 알려지지 않은 예외를 AI가 일반화하는 것보다 충돌로 표시해
사람이 확인하게 하는 편을 선호했다.

온보딩에는 통합 문서가 유용하지만 긴급 대응에서는 검증 상태와 마지막 승인
상태가 한눈에 보여야 한다.
