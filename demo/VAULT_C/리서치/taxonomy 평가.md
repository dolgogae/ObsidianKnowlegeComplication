# Taxonomy 평가

좋은 taxonomy는 모든 문서를 한 번씩 포함하면서 사용자가 예상하는 업무 용어를
경로로 사용한다. 기술 component만으로 분류하면 고객의 도입 질문과 운영 절차가
여러 cluster로 찢어졌다.

## 검토 질문

- singleton 문서도 의미 있는 위치를 갖는가
- 날짜별 기록이 주제 문서와 연결되는가
- 같은 제목의 문서가 source 맥락 없이 합쳐지지 않는가
- canonical path가 안전하고 사람이 예측 가능한가
- rename 또는 split 이유가 revision에 남는가

검토 결과는 [[회의/파일럿 검토]]와 [[고객/파일럿 회고]]에 전달한다.
