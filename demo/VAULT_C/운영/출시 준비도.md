# 출시 준비도

## 완료

- source 선택과 preflight 교육 자료
- taxonomy와 cluster 검토 책임자 지정
- 기존 output을 덮어쓰지 않는 실행 경로
- verify 결과를 기록하는 체크리스트

## 미완료

- 실제 terminal에서 provider crash 복구 훈련
- 지원 담당자의 야간 escalation 연습
- 보존 기간에 대한 제품팀과 운영팀 합의
- 파일럿 종료 기준과 rollback owner 확정

따라서 고객 운영이 선호하는 2026-10-29는 조건부 제안이다. 준비 항목이 남으면
엔지니어링 제안 이후로 미룬다. 논의 기록은 [[회의/출시일 조정]]에 있다.
