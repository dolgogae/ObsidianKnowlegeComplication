# 경쟁 제품 메모

일반 검색 제품은 수집과 질의가 빠르지만 문서 통합 결과를 파일로 다시 내보내는
과정이 약하다. 문서 관리 제품은 협업 편집에 강하지만 기존 Vault를 불변 source로
취급하는 감사 흐름은 드물다.

Atlas가 차별화할 수 있는 지점은 다음과 같다.

- 결과 문장과 source block 사이의 추적성
- 충돌을 숨기지 않는 검토 모델
- provider 호출과 최종 compile의 분리
- 기존 Obsidian 파일 구조를 유지한 입력 방식

이 비교는 공개 가격이나 최신 기능을 검증한 시장 분석이 아니라 제품 방향을
정리하기 위한 내부 메모다.
