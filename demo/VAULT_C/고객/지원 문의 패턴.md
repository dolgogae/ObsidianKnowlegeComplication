# 지원 문의 패턴

## 자주 나오는 질문

- 왜 두 문서가 같은 cluster에 들어갔는가
- 어떤 source 문장이 canonical section의 근거인가
- 오래된 절차가 왜 삭제되지 않고 충돌로 남아 있는가
- provider 연결 없이 이미 승인한 결과를 다시 만들 수 있는가
- 취소한 실행은 어느 단계부터 이어지는가

사용자는 매끄러운 요약보다 적용 환경과 마지막 검증 상태를 먼저 찾았다. 이를
[[고객/교육 계획]]과 [[리서치/파일럿 질의 세트]]에 반영한다.

장애성 문의는 [[운영/장애 대응 절차]]로, 데이터 공개 질문은
[[거버넌스/감사 응답 절차]]로 연결한다.
