# 리서치 MOC

## 입력과 질의

[[리서치/평가 데이터셋]]과 [[리서치/파일럿 질의 세트]]가 평가 범위를 정의한다.

## 평가

- [[리서치/검색 평가]] — 후보와 탐색 성공
- [[리서치/taxonomy 평가]] — 문서 배정과 이름의 유용성
- [[리서치/합성 품질 기준]] — 근거, 누락, 충돌, 읽기 쉬움

결과는 [[고객/파일럿 회고]]와 [[회의/파일럿 검토]]에서 운영 판단으로 연결한다.
