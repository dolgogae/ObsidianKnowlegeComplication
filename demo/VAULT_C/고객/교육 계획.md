# 교육 계획

첫 세션은 Vault 선택과 preflight, 둘째 세션은 taxonomy와 cluster review, 셋째
세션은 compile, verify, provenance 설명을 다룬다.

실습자는 [[고객/온보딩 체크리스트]]로 한 번의 실행을 완료한 뒤 일부러 taxonomy
이름을 수정해 이전 proposal이 stale이 되는 것을 관찰한다. 다음으로 provider를
끈 상태에서 승인된 plan을 compile해 offline boundary를 확인한다.

교육 자료에는 자동 승인이 없다는 점과 output이 백업이 아니라는 점을 반복한다.
자주 묻는 질문은 [[고객/지원 문의 패턴]]에서 갱신한다.
