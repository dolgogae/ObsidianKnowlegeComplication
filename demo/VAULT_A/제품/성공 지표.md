# 성공 지표

## 파일럿 지표

- taxonomy 검토 후 잘못 묶인 문서 비율이 낮아지는가
- canonical 문서의 주장마다 source 근거를 찾을 수 있는가
- 오래된 복사본 때문에 생기는 검색 실패가 감소하는가
- 검토자가 누락 제안을 식별하고 이유를 기록할 수 있는가
- 통합 전후에 source 파일 해시가 동일한가

정량 값만으로 품질을 단정하지 않는다. 파일럿 종료 인터뷰에서 신뢰도, 검토
피로, 원본 추적성에 대한 설명을 함께 수집한다. 검색 지표는 [[리서치/검색 결과 관찰]]과
연결해 해석한다.
