# 핵심 시나리오

## 주간 지식 통합

팀 리드는 세 Vault의 스냅샷을 선택하고 변경 범위를 확인한다. Atlas는 문서를
주제별로 묶고, 각 주제의 초안을 제안한다. 리드는 누락과 충돌을 확인한 뒤
승인하고 새로운 통합 Vault를 배포한다.

## 신규 구성원 온보딩

신규 구성원은 통합 Vault의 canonical 문서부터 읽고, 세부 맥락이 필요하면
원본 위치를 가리키는 링크를 따라간다. 제품 용어와 기술 용어가 다르면 두
표현이 같은 개념인지 명시적으로 설명되어야 한다.

## 변경 사항 감사

운영 담당자는 특정 문장이 어떤 source 문서와 승인에서 왔는지 확인한다.
검증 실패 시 결과를 사용하지 않고 이전에 검증된 Vault를 유지한다.
