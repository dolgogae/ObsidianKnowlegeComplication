# 거버넌스 MOC

[[거버넌스/데이터 분류]]가 provider route의 출발점이다. 누가 무엇을 승인하는지는
[[거버넌스/승인 역할]], 얼마나 보존하는지는 [[거버넌스/보존 정책]]에서 다룬다.

외부 질문에는 [[거버넌스/감사 응답 절차]]를 사용한다. 아직 닫히지 않은 위험과
owner는 [[거버넌스/위험 등록부]]에 남긴다.
