# 파일럿 질의 세트

- 파일럿 시작일은 언제이며 아직 닫히지 않은 조건은 무엇인가
- source Vault가 변경되면 어떤 승인이 stale이 되는가
- 민감한 문서가 탐지되면 어떤 provider route가 필요한가
- provider 없이 다시 수행할 수 있는 단계는 무엇인가
- 검색 후보에 semantic 외 어떤 신호가 포함되는가
- output 문장의 source block을 어떻게 찾는가
- project 기록과 output의 보존 기간 제안은 왜 다른가
- attachment와 Canvas는 현재 파일럿 결과에 포함되는가

^pilot-queries

질의별 근거 문서는 [[리서치/평가 데이터셋]]에 고정하고, 결과 분석은
[[리서치/검색 평가]]와 [[리서치/합성 품질 기준]]에서 나누어 수행한다.
