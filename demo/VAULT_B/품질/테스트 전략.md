# 테스트 전략

unit test는 identity, parser, schema validation, approval invalidation을 다룬다.
integration test는 project 생성부터 compile과 verify까지 같은 service 경계를
통과해야 한다.

필수 실패 사례에는 source symlink, path traversal, 기존 output, stale taxonomy,
foreign evidence, 누락 disposition, unwaived critic finding, malformed provider
response가 포함된다.

결정성 검사는 같은 fixture와 recording으로 두 번 생성한 전체 bytes를 비교한다.
source 불변성은 실행 전후 파일 hash와 metadata를 확인한다. 화면 테스트와 실제
PTY keyboard test는 서로 대체하지 않는다.
