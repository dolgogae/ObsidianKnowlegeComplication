# 파일럿 개요

파일럿 대상은 문서가 여러 팀 Vault에 흩어져 있고, 결정의 최신성과 출처를
확인하는 데 반복적으로 시간이 드는 내부 운영 그룹이다.

## 목표

- 세 Vault를 한 번의 검토 흐름으로 통합한다.
- 원본 표현과 canonical 설명 사이를 provenance로 오갈 수 있다.
- 충돌과 누락을 숨기지 않고 curator가 명시적으로 판단한다.
- provider 장애 뒤 작업을 처음부터 반복하지 않고 안전하게 재개한다.

시작 후보일은 2026-10-29이지만 [[회의/출시일 조정]]에서 아직 확정하지 않았다.
실행 과정은 [[고객/도입 플레이북]], 평가는 [[리서치/리서치 MOC]]를 따른다.
