# 고객 운영 로드맵

## 단계 1: 내부 파일럿

Markdown-only directory 결과로 taxonomy와 evidence review의 가치를 확인한다.
[[고객/파일럿 개요]]와 [[운영/출시 준비도]]가 gate다.

## 단계 2: 반복 운영

변경 주기, 보존, 장애 대응, 교육을 표준화한다. 근거는 [[고객/파일럿 회고]]와
[[리서치/리서치 MOC]]에서 가져온다.

## 단계 3: 범위 확장 검토

attachment, Canvas, pack 설치는 구현과 안전성 evidence가 생긴 뒤 검토한다.
현재 지원되는 기능처럼 고객에게 약속하지 않는다.
