# 비즈니스 용어집

## 파일럿

제한된 내부 사용자와 Markdown 범위에서 review workflow를 검증하는 기간.
[[고객/파일럿 개요]] 참고.

## curator

taxonomy와 cluster revision을 source evidence와 대조해 승인하는 사람.
[[거버넌스/승인 역할]] 참고.

## canonical note

하나의 승인된 cluster에서 생성된 탐색 시작점. source를 삭제하거나 대체하지
않는다. [[리서치/합성 품질 기준]] 참고.

## provenance

output에서 proposal, approval, source document와 block으로 이어지는 감사 관계.
[[거버넌스/감사 응답 절차]] 참고.
